## Reproduction

- `tools/sprites/large_scorpion/generate_source.py` rebuilds the SpriteU JSON as
  four64px quadrant clips per native128px pose. This handles SpriteU's cell limit
  without scaling pixels. Rig+transition sources are in the same folder.
- `tools/sprites/pack_scorpion_spriteu.py` reconstructs1024x4992 atlas and64 Godot
  SpriteFrames clips, exact timing in each frame. Verified byte-identical to
  handoff atlas; full generator source semantically identical to approved JSON.
- `export_geometry.py` in the rig folder instruments the actual terminal triangle
  and feet, then follows real transition masking/sand.312 poses. Hidden vertices
  stay hidden, never relocated to another dark pixel. Compact runtime table is
  generated by `tools/sprites/pack_scorpion_geometry.py` from metadata.
- All96 transition PNGs match approved atlas frames byte-for-byte.
- Obsolete64px append generator refuses the new source to prevent corruption.
